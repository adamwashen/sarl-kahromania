# Groupe Al-Ryada — Sarl Kahromania

## Ce qui est inclus
- Boutique responsive avec fond noir et accents orange.
- Produits et panier.
- Commande uniquement via WhatsApp : +213540588197.
- Section « Vente en gros » séparée.
- Dashboard Admin intégré.
- Accès Admin : cliquer 5 fois sur le logo/nom « Groupe Al-Ryada » en haut, puis entrer `1245`.
- Modification des noms, prix, descriptions et URL des images.
- Modification du numéro WhatsApp et des textes principaux.
- Les modifications sont sauvegardées dans le navigateur avec localStorage.

## Important
Cette version est une boutique statique. Les changements du Dashboard sont enregistrés sur le navigateur/appareil où ils sont effectués.
Pour que le client puisse modifier le site depuis n'importe quel téléphone/PC et que les changements soient visibles pour tout le monde, il faudra connecter le Dashboard à une base de données/backend (par exemple Supabase/Firebase) et sécuriser l'authentification.

## Mise en ligne
Décompresser le ZIP et mettre `index.html`, `styles.css` et `app.js` dans l'hébergement. Aucun build n'est nécessaire.
